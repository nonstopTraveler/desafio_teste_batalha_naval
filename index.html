Batalha Naval

Para dois jogadores no mesmo dispositivo

Como funciona

  • Cada jogador tem uma frota em um tabuleiro 10 x 10: Porta-aviões (5 casas), Encouraçado (4), Submarino (3) e Destroier (2).
  • Os navios são posicionados automaticamente e ficam escondidos do adversário.
  • A cada vez, clique em uma casa do tabuleiro do adversário para atirar. Os jogadores se alternam depois de cada tiro.
  • Vence quem afundar todos os navios do adversário primeiro.

Passe o dispositivo para essa pessoa. Os tabuleiros só aparecem depois do clique.
